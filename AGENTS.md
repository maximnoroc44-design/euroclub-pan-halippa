# Reguli esențiale

- Site static: păstrează HTML/CSS/JavaScript vanilla, fără framework-uri sau dependențe inutile.
- Fișierele principale sunt index.html, style.css, script.js și assets/images/; folosește căi relative, compatibile cu GitHub Pages.
- Logo-ul oficial nu se modifică. Publică numai fotografii aprobate și informații confirmate.
- Nu inventa nume, rezultate, statistici, parteneri, bugete, date de contact sau linkuri sociale.
- Pentru informații lipsă, menține blocurile de completare; nu introduce date personale sau secrete.
- Menține accesibilitatea, versiunea mobilă, reduced motion și funcțiile galeriei după orice editare.
- Nu schimba vizibilitatea repository-urilor și nu adăuga chei, tokenuri ori servicii cu plată.
- După o editare semnificativă, fă o singură verificare locală concentrată și actualizează README dacă se schimbă fluxul de editare.
